LLM Management System

Project Description

The LLM Management System is an AI-powered Student Management System designed to simplify academic management and monitor student performance.

Features

- Student, Faculty, and Admin Dashboards
- Student Attendance Management
- Grade Prediction
- Dropout Risk Analysis
- Personalized Study Recommendations
- AI-Based MCQ Generation

Technologies Used

- Python
- Flask
- Google Gemini API
- SQLite
- HTML
- CSS
- JavaScript

Key Highlights

- Integrated Google Gemini API for AI-based question generation.
- Developed dashboards for managing student information.
- Implemented attendance tracking and academic performance analysis.

Project Purpose

To improve student performance monitoring and support academic decision-making using AI.
